## Priorisation (fit score) — critères hérités du sweep
1. Le client a clairement un budget/du capital.
2. Correspond à un des 3 modèles (partenariat / retainer / one-shot).
3. Récent (<30 jours) et encore ouvert.
4. Peu de concurrence sur l'annonce.
5. Pertinence COD/MENA = avantage décisif de Khalid.

## Rappels appris sur le terrain
- **Mostaql = plateforme n°1** pour cette niche (projets AR publics indexés) — mais propositions
  via la plateforme uniquement (pas d'email) → les lister dans le rapport pour action manuelle.
- Mostaql/Khamsat bloquent le fetch direct (403) : les IDs de projet élevés = récents.
- Upwork/LinkedIn posts/X = login wall → lister les URLs de recherche dans le rapport, pas de scraping.
- Les emails publiés se trouvent surtout : offres d'emploi (job boards), pages contact d'agences,
  sites d'entreprises e-com qui recrutent. PAS sur les plateformes freelance.
