# 6. Portfolio — transformer ton expérience en preuve vendeuse (vite)

> Problème : tu as l'expérience mais pas de portfolio organisé. Solution : 3 études de cas d'UNE page chacune + 1 offre assez forte pour vendre même sans historique public. Total : 1 journée de travail.

## A. Template d'étude de cas (1 page, format PSR : Problème → Solution → Résultat)

```
📦 [Type de produit] — [Marché] — [Période]

LE CONTEXTE (2 lignes)
Client/projet : [boutique COD, marché X]. Situation de départ : [ex. ROAS 1.2, taux de livraison 45 %, perte nette].

CE QUE J'AI FAIT (3-5 puces max)
• [Recherche produit : méthode + outil]
• [Refonte landing page : quels éléments]
• [Structure de campagne : budget, audiences, créatives testées]
• [Optimisation logistique : confirmation calls, transporteur]

LE RÉSULTAT (chiffres AVANT → APRÈS)
• ROAS livré : 1.2 → 2.4
• Taux de livraison : 45 % → 62 %
• Coût par commande livrée : X → Y
[+ 1 capture d'écran anonymisée]

CE QUE ÇA MONTRE : [1 phrase — la compétence précise que ce cas prouve]
```

## B. Quoi screenshotter (honnêtement, sans données confidentielles)

✅ **À capturer** :
- Ads Manager : colonnes dépense / achats / ROAS — **masque** le nom du compte, les noms de campagnes identifiables et les URLs.
- Dashboard livraisons (Shipeh, Google Sheet de suivi) : commandes vs livrées — masque noms/téléphones clients.
- Créatives que TU as conçues (elles t'appartiennent comme preuve de savoir-faire).
- Landing pages : capture plein écran, masque le domaine si le client l'exige.

❌ **Jamais** : données clients nominatives, chiffres inventés ou « améliorés », captures de comptes qui ne sont pas les tiens, promesses de résultats garantis chiffrés.

**Règle d'or de l'anonymisation** : « boutique mode féminine, marché marocain » suffit — le secteur + le marché rendent le cas crédible sans trahir le client.

## C. Pas encore de « vrais » cas clients ? Fais ceci cette semaine

1. **Ton propre projet compte.** Ton étude de marché Libye (12 produits, Meta Ad Library, analyse concurrents, marges LYD) est DÉJÀ une étude de cas — elle prouve ta méthode de recherche produit mieux que 90 % des portfolios. Formate-la au template PSR : « Comment je sélectionne un produit COD avec des données réelles plutôt qu'au feeling ».
2. **Audit gratuit filmé** : propose à 2 boutiques de ton réseau un audit gratuit contre le droit d'utiliser le cas anonymisé.
3. **Side-by-side** : prends une landing page COD publique moyenne et refais-la à ta façon — le avant/après démontre la compétence sans client.

## D. Vendre AVANT que le portfolio soit épais : l'offre forte

Le portfolio réduit le risque perçu. Sans portfolio épais, réduis le risque par L'OFFRE :

| Levier | Formulation |
|---|---|
| **Garantie performance** | « Si au bout de 30 jours le coût par commande livrée n'a pas baissé, le 2ᵉ mois de gestion est gratuit. » |
| **Entrée à petit prix** | Audit 15 min gratuit → plan d'action payant à prix bas (50-100 $) → gestion mensuelle. Chaque étape prouve la suivante. |
| **Partenariat profit-share** | L'offre ultime « zéro risque perçu » : « je ne gagne que si vous gagnez ». C'est ton modèle 1 — il ne demande AUCUN portfolio, seulement de la confiance construite en appel + transparence (dashboard partagé). |
| **Transparence méthode** | Montre COMMENT tu travailles (ta checklist produit, ta structure de campagne) — la méthode visible remplace les résultats passés. |

⚠️ Garantie ≠ promesse de gains : garantis ton TRAVAIL (améliorations mesurables, livrables) jamais un chiffre de profit — c'est à la fois honnête et légalement plus sûr.

## E. Où héberger le portfolio (gratuit, 1 h)
- **Notion** page publique (le plus rapide) ou **Google Drive** PDF propre.
- Lien dans : bio LinkedIn, profils Upwork/Mostaql, signature de chaque proposition.
- Nom du fichier/page : « [Ton nom] — COD E-commerce Specialist — Case Studies ».
