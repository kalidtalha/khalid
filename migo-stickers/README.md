# 🍯 MiGO — مكتبة ستيكرات العسل (Bottle Stickers Library)

مولّد ستيكرات/ملصقات احترافية لقارورات **عسل ميغو الطبيعي**.
كل ستيكر مقاس **1080×1080** (مربّع — إنستغرام / طباعة)، بنفس الهوية (أسود + ذهبي + لوجو النحلة).

|---|---|---|---|---|

## البنية (Structure)
```
migo-stickers/
├── src/bee-logo.svg      # لوجو النحلة MiGO (SVG — قابل لإعادة الاستعمال)
├── fonts/                # خطوط عربية (Cairo Black/Bold/SemiBold, Amiri)
├── build.js              # المولّد — كيصنع HTML لكل نوع/حجم
├── build/                # ملفات HTML مولّدة (وسيطة)
├── output/               # 🎯 الصور النهائية PNG 1080×1080
└── render.sh             # يبني + يصوّر الكل PNG
```

## كيفاش تعاود تولّد (Regenerate)
```bash
cd migo-stickers
./render.sh          # يبني الـ HTML ويصوّر جميع الستيكرات PNG
```

## كيفاش تبدّل / تزيد
- **تبديل رقم/انستغرام:** بدّل `BRAND` فـ `build.js` وعاود `./render.sh`.
- **تزيد نوع جديد** (مثلا الأوكاليبتوس): زيد entry فـ `TYPES` (الاسم + الألوان) وعاود.
- **تزيد حجم** (مثلا 750g): زيد entry فـ `SIZES`.
- **النص/التصميم:** كلشي فـ `build.js` (CSS داخل القالب).

> ملاحظة: التصميم مبني بـ HTML/CSS/SVG ومصوّر بـ Chromium — النص العربي دقيق 100% ونفس النتيجة فكل مرة.
